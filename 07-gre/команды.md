# 7. GRE

Перед туннелем с HQ-RTR: `ping 172.16.2.2`

## HQ-RTR

```
interface tunnel.0
ip address 10.10.10.1/30
ip tunnel 172.16.1.2 172.16.2.2 mode gre
exit
write memory
show interface tunnel.0
ping 10.10.10.2
```

## BR-RTR

```
interface tunnel.0
ip address 10.10.10.2/30
ip tunnel 172.16.2.2 172.16.1.2 mode gre
exit
write memory
show interface tunnel.0
ping 10.10.10.1
```
