# 10. DHCP

Пул `10.10.200.2`–`10.10.200.14`. Адрес роутера `.1` в пул не входит.

## HQ-RTR

```
ip pool VLAN200 10.10.200.2-10.10.200.14
dhcp-server 1
pool VLAN200 1
mask 28
gateway 10.10.200.1
dns 10.10.100.2
domain-name au-team.irpo
exit
exit
interface vl200
dhcp-server 1
exit
write memory
show running-config dhcp-server 1
show dhcp-server clients vl200
```

## HQ-CLI

```
ip -c a
cat /etc/resolv.conf
```

Адрес из `10.10.200.2`–`14`, шлюз `10.10.200.1`, DNS `10.10.100.2`, домен `au-team.irpo`.
