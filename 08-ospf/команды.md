# 8. OSPF

Пароль MD5: `P@ssw0rd`, key-id `1`.

## HQ-RTR

```
router ospf 1
passive-interface default
no passive-interface tunnel.0
network 10.10.10.0/30 area 0
network 10.10.100.0/27 area 0
network 10.10.200.0/28 area 0
network 10.10.30.0/29 area 0
area 0 authentication message-digest
exit
interface tunnel.0
ip ospf authentication message-digest
ip ospf message-digest-key 1 md5 P@ssw0rd
exit
write memory
```

Проверка:

```
show ip ospf neighbor
show ip ospf interface tunnel.0
show ip route ospf
```

Сосед один: `10.10.10.2`, состояние Full.

## BR-RTR

```
router ospf 1
passive-interface default
no passive-interface tunnel.0
no passive-interface fw
network 10.10.10.0/30 area 0
network 10.20.10.0/30 area 0
area 0 authentication message-digest
exit
interface tunnel.0
ip ospf authentication message-digest
ip ospf message-digest-key 1 md5 P@ssw0rd
exit
interface fw
ip ospf authentication message-digest
ip ospf message-digest-key 1 md5 P@ssw0rd
exit
write memory
```

Проверка:

```
show ip ospf neighbor
show ip ospf interface fw
show ip route ospf
```

Соседа два, оба Full: `10.10.10.1` на `tunnel.0` и адрес Ideco на `fw`.

## BR-FW

Меню → Маршрутизация → OSPF:

- Аутентификация соседей: MD5, Key ID `1`, пароль `P@ssw0rd` → Сохранить
- Локальные интерфейсы, область `0`, тип Normal:
  - `oif0` — к BR-RTR
  - `iif0` — сеть BR-SRV
  - `iif1` — сеть BR-CLI
- Тумблер OSPF: статус «Работает»
