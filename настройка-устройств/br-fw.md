# BR-FW

Ideco, веб-интерфейс. Адреса — сразу после BR-RTR. OSPF — после GRE, вместе с OSPF на роутерах.

## 1. Адреса

Инфраструктура → Настройки сети.

- `oif0`, интерфейс к BR-RTR: `10.20.10.2/30`, шлюз по умолчанию `10.20.10.1`
- `iif0`, интерфейс к BR-SRV: `10.20.20.1/28`
- `iif1`, интерфейс к BR-CLI, если он есть на стенде: `10.20.30.1/29`

Без шлюза `10.20.10.1` BR-SRV не выйдет в интернет, и NAT на BR-RTR останется пустым.

## 2. OSPF

Меню → Маршрутизация → OSPF. Делать, когда туннель между роутерами уже пингуется.

Аутентификация соседей: MD5, Key ID `1`, пароль `P@ssw0rd` → Сохранить.

Дополнительные → Локальные интерфейсы → Добавить. Область `0`, тип Normal, остальное по умолчанию:

- `oif0` — смотрит на BR-RTR, без него соседа не будет
- `iif0` — сеть BR-SRV, чтобы головной офис узнал маршрут `10.20.20.0/28`
- `iif1` — сеть BR-CLI, если она есть

Включить тумблер OSPF вверху страницы. Статус должен стать «Работает».
